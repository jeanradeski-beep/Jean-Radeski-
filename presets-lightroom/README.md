# Presets Lightroom · BR Sem Fronteiras

Baseados no estilo do @br.semfronteiras: quente e aconchegante, sombras profundas,
luzes âmbar, verdes puxados para oliva e céus de pôr do sol / hora azul.

| Preset | Quando usar | Exemplo do perfil |
|---|---|---|
| BRSF 01 Refúgio Natural | Dia, mata, fachadas de cabana | Cabanas Doce Encanto, Container Zero Um |
| BRSF 02 Aconchego Noturno | Noite com luzes quentes | AJ Geodos à noite, Lunnare, Forquilha |
| BRSF 03 Pôr do Sol Dourado | Golden hour / pôr do sol | Sky Capsule, Parque Tanguá, domo |
| BRSF 04 Hora Azul | Céu azul-rosado + luzes acesas | Rifugio ao anoitecer |
| BRSF 05 Drone Terroso | Aéreas e paisagens amplas | AJ Termas vista de drone |

## Como instalar
- **Lightroom (celular):** baixe o `.zip`, extraia, abra uma foto → `Predefinições` → `⋯` → `Importar predefinições` → selecione os `.xmp`.
- **Lightroom (desktop/CC):** `Arquivo → Importar perfis e predefinições` → selecione o `.zip`.
- **Lightroom Classic:** painel Predefinições → `+` → `Importar predefinições`.

Aparecem no grupo **BR Sem Fronteiras**.

## Dicas
- Depois de aplicar, ajuste só **Exposição** e **Temperatura** foto a foto.
- Use o controle **Intensidade** (Amount) para suavizar: 60–80% costuma bastar em JPG de celular.
- Em RAW os presets funcionam melhor (mais margem nas altas luzes).
